# Jie

轻量的 Windows / macOS 截图工具，支持截图、标注、钉图、录屏（GIF）、取字和翻译。

## 功能

- **截图**：快捷键唤起，拖动框选或点击选中吸附的区域，支持调整选区。吸附能认出窗口，也能认出页面里的面板、卡片、输入框、侧栏、表格格子这些边界：默认高亮鼠标下的主要区域（聊天区、编辑区、侧栏这类大面板，没有就是整个窗口），滚轮往上换外面一层、往下换里面更小的一层。
- **标注**：矩形、椭圆、箭头、画笔、文字、序号、马赛克，支持撤销和重做。
- **钉图**：把截图置顶在桌面，支持拖动、缩放、调整透明度。鼠标停在钉图上，下面出现操作条：编辑标注、取字、翻译、复制、保存、关闭（动图钉图第一个是暂停/播放）；右键菜单也能用。
- **录屏**：框选区域（吸附、选区颜色都同截图）后录成 GIF，带鼠标指针；点了就开始录（选区操作栏上可以选延时 3、5、10 秒，在区域中间倒数），录制时区域外有一圈选区颜色的边框，旁边的控制条显示时长、文件大小和停止、放弃按钮。框和控制条放在区域外面，不会录进去，远程桌面、会议共享里也看得到；全屏录制时控制条放在任务栏上。停止后动图在原位置循环播放，外面一圈选区颜色的框（设置里可以关），下面的结果条写着时长和大小，可以复制、保存、钉在屏幕上或丢弃。帧率可在设置里选 10 / 15 / 20 / 30。
- **取字与翻译**：识别截图里的文字并翻译，在文字卡片里查看、选择和复制；卡片标题栏「识别 | 翻译」两个标签，识别完切到翻译就地翻译。
- **输出**：复制图片到剪贴板，或保存为 PNG、JPEG。

## 使用

**Windows**：要求 Windows 10 22H2 或更新版本，主要在 Windows 11 上测试。解压便携包 `Jie-<版本>-portable.zip`，运行 `jie.exe`。程序未签名，首次运行可能出现 SmartScreen 提示。

**macOS**：要求 macOS 14 或更新版本、Apple 芯片。目前供本机构建使用，步骤见[开发说明](docs/development.md)。打开 `Jie.app` 后，首次截图需要在「系统设置 → 隐私与安全性 → 屏幕录制」允许 Jie，再重新打开应用。

程序常驻托盘或菜单栏：左键截图，右键（macOS 上也可以按住 Control 点）打开面板：截图、录屏（录制中是「停止录屏」和时长），屏幕上的钉图、文字卡片各有「全部关闭」，设置、退出；点外面或 `Esc` 关掉，方向键、`Enter` 也能操作。设置分三页：常规（两个快捷键、开机自启、选区颜色）、截图与录屏（保存位置和格式、录屏帧率、动图边框）、文字与翻译。

**录屏**：截图和录屏是同一个遮罩，顶上的模式条切换（或按 `Tab`）；两个快捷键只决定打开时是哪个模式。有标注时切不到录屏（标注录不进去），撤销完就能切。框选区域后点「开始录制」（或 Enter）马上开始；要延时就在选区操作栏上点「3 秒」「5 秒」「10 秒」（本次运行内记住，重启后回到不延时）；倒数时可以点控制条上的「立即开始」或「取消」。录制中再按一次录屏或截图快捷键、单击托盘图标，或点控制条上的「停止」结束；「放弃」不留文件。框满整块屏幕（连任务栏）时控制条放在区域里的任务栏上，照样看得到（远程桌面里也是）；录的时候 Windows 用系统放大镜的排除功能把控制条去掉，那块录到的还是实时画面，不会把控制条录进去。录好的 GIF 先存在临时文件夹里，下次启动时清掉，要留下请点「保存」。复制时剪贴板里放的是 GIF 文件，粘贴到聊天软件、浏览器、资源管理器或访达里就是动图。

## 快捷键

下表中的 `Ctrl` 在 macOS 上换成 `⌘`；开始截图默认是 `⌥⇧A`，录屏默认是 `⌥⇧S`。

| 操作 | 按键 |
|---|---|
| 开始截图 | `Alt+Shift+A`（可在设置中修改） |
| 录屏 | `Alt+Shift+S` 打开录屏模式的遮罩，录制中再按一次停止（可在设置中修改） |
| 截图 / 录屏切换 | 遮罩里按 `Tab` |
| 吸附换层 | 没有选区时滚轮：往上换外面一层，往下换里面一层 |
| 复制选区 | `Enter`、双击、`Ctrl+C` |
| 保存 | `Ctrl+S` |
| 取消截图 | `Esc` 一次退出（文字输入中先结束输入）；右键有选区时先清掉选区，无选区时退出 |
| 标注工具 | `R` 矩形 · `E` 椭圆 · `A` 箭头 · `P` 画笔 · `T` 文字 · `N` 序号 · `M` 马赛克 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z`、`Ctrl+Y` |
| 删除标注 | `Delete`、`Backspace` |
| 钉图 | 滚轮缩放 · `Ctrl+滚轮` 调透明度 · `Ctrl+C` 复制 · 双击或 `Esc` 关闭 |
| 录屏结果 | `Enter`、双击、`Ctrl+C` 复制 GIF · `Ctrl+S` 保存 · `Esc` 丢弃 |

## 配置取字和翻译

1. 右键托盘或菜单栏图标 → 设置… → 文字与翻译。
2. 填写支持 OpenAI 兼容接口的服务地址、模型和 API Key，点击「测试连接」。默认预填 DeepSeek。
3. 「另用一家服务识别文字」关着时取字也用上面的服务；打开后单独填识别的地址、模型和 Key（留空的项沿用上面的）。取字所用模型必须支持图片输入；开着时「测试连接」会再发一张图测识别服务。
4. 点击「确定」保存。取字结果不会自动复制，需在文字卡片中手动复制。

取字会把**选区截图**发送给识别服务，翻译再把识别出的文字发送给翻译服务。没有离线识别；服务地址须使用 HTTPS（localhost 除外）。普通截图、标注和钉图无需配置服务。

API Key 保存在 Windows 凭据管理器或 macOS 钥匙串中，不写入配置文件。其他设置位于：

- Windows：`%APPDATA%\Jie\settings.json`
- macOS：`~/Library/Application Support/Jie/settings.json`
